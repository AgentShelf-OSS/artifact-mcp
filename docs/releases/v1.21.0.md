# Artifact MCP v1.21.0

## Listen and the artifact library in the Android app (ADR-0019)

- **Listen mirrored to the app.** Inside the Artifact MCP Android app, Listen reports its state as
  `media.session` messages. The app shows it in Android Auto, the media notification and Bluetooth
  controls. Their buttons come back as `media.command` and press the same Listen controls. This is
  enabled only when the app advertises `media.mirror`.
- **`GET /api/library`.** Returns the signed-in viewer's visible artifacts grouped by organization,
  newest first, at most 200 per organization, without hidden uploads. A missing session returns
  `403 {"error":"not_signed_in"}`. Implemented in both runtimes.
- **`?listen=autoplay`.** Starts Listen once the reader is ready, only inside the native host. The
  app uses it when an artifact is picked from the car's library. Browsers ignore it.

## Schema and configuration

No schema change (40). No new configuration.

## Deployment and rollback

To roll back, restore the v1.20.0 binary. App versions that use the library then show their cached
list or a sign-in item.

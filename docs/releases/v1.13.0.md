# Artifact MCP v1.13.0

## Scheduled reminders with phone notifications

Artifacts can now alert people when the page is closed or the phone is locked. ADR-0012 records the
design. The first user is a family baby log that reminds parents to change a diaper every two hours.

- An artifact asks the viewer shell to set, replace, or clear a named reminder with a time, a
  title, and a body (`reminder:*` messages). It cannot choose recipients or URLs.
- Publishers can do the same with the new MCP tool `set_artifact_reminder` (organization scope).
- Viewers turn notifications on for each artifact from a bell in the viewer toolbar. The shell
  registers a minimal service worker (`/sw.js`) that only shows notifications and never handles
  fetches. iPhone users must add the site to the Home Screen first (iOS 16.4 or later).
- A Rust sweeper fires due reminders to opted-in viewers in the artifact's current organization,
  and to opted-in administrators. A leased sender delivers them with Web Push: VAPID (RFC 8292)
  and `aes128gcm` payload encryption (RFC 8291).
- The server only sends to push-service hosts on the `WEB_PUSH_ENDPOINT_HOSTS` allowlist, both
  when a subscription is saved and before each send.

The Node reference implements the routes, storage, and MCP tool. Only the Rust server sends
notifications.

## Schema and configuration

Migration 39 adds `push_subscriptions`, `artifact_push_optins`, `artifact_reminders`, and
`push_deliveries`. Subscription endpoints are encrypted with `WEBHOOK_ENC_KEY`.

New environment variables (the feature is off until all are set):

| Variable | Purpose |
|---|---|
| `WEB_PUSH_VAPID_PRIVATE_KEY` | base64url P-256 private key. Generate it with `node scripts/web-push-keys.mjs`. Treat it as a secret. |
| `WEB_PUSH_SUBJECT` | `mailto:` or `https:` contact for push services |
| `WEB_PUSH_ENDPOINT_HOSTS` | Optional. Overrides the default push-service host allowlist |

`WEBHOOK_ENC_KEY` must also be configured. Rotating the VAPID key invalidates every subscription.
Viewers must then turn notifications on again.

New unauthenticated static routes: `/sw.js`, `/manifest.webmanifest`, `/icons/*.png`. They hold no
private data. The artifact IDs `sw.js`, `manifest.webmanifest`, and `icons` are now reserved.

## Deployment and rollback

Verify the release checksums, manifest, and attestations before installation. Keep the v1.12.2
binary, its deployment record, and the pre-deploy backup for rollback. Migration 39 only adds
tables. A rollback to v1.12.2 restores the pre-deploy backup, so it uses schema 38.

# Artifact MCP v1.16.0

## Pluggable Pocket voices

Adding a Listen voice no longer needs a code change.

- **Worker.** Set `POCKET_TTS_VOICE_DIR` (the Compose file mounts `./voices` at `/voices`) and
  drop `<id>.safetensors` voice states into it: public Pocket presets or voices exported from a
  consenting speaker's recording. Invalid, colliding, symlinked or oversized files are skipped
  with a warning. Replacing a file never serves stale cached audio.
- **Server.** `POCKET_TTS_EXTRA_VOICES=id:Label[:gainDb],...` makes those voices selectable and
  sets each one's loudness gain. Invalid values fail startup in both runtimes.
- `/{id}/speech/voices` now reports `gainDb` for Pocket voices; the built-in preset gains moved
  from the player to the server. The player still falls back to its own table.

Only add cloned voices when the speaker has given explicit written consent for synthetic
narration. Public-domain recordings are not consent. See `ops/pocket-tts/README.md`.

## Schema and configuration

The schema remains 39. New optional variables: `POCKET_TTS_EXTRA_VOICES` (artifact server) and
`POCKET_TTS_VOICE_DIR` (Pocket worker). Without them, behaviour is unchanged.

## Deployment and rollback

Deploy the server first, then the worker voices, then set `POCKET_TTS_EXTRA_VOICES`. Keep the
v1.15.0 binary for rollback; remove the variable before rolling back, because v1.15.0 does not
accept extra voices.

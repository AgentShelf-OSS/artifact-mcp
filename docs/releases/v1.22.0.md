# Artifact MCP v1.22.0

## Pocket voice catalog and voice picker (ADR-0020)

- **`POCKET_TTS_VOICE_CATALOG`.** An optional JSON catalog of up to 400 Pocket voices with labels,
  gains and tags (gender, accent, style, source). Entries add voices or override built-in ones. Both
  runtimes re-read it when it changes, with no restart. An invalid file is logged and ignored.
- **Voice list tags.** `/:id/speech/voices` entries may include
  `tags: {gender?, accent?, style?, source}`.
- **Find a voice.** With 12 or more voices, the Listen panel adds search, Female, Male and Saved
  filters, an accent menu and "Save this voice". Saved voices stay in this browser for every
  artifact.
- **Pocket worker (ops).** `ops/pocket-tts` loads prepared voices from a manifest-driven directory.
  Includes the Kyutai donation audition tooling and the catalog generator `voice_catalog.py`.

## Schema and configuration

No schema change (40). New optional setting: `POCKET_TTS_VOICE_CATALOG`.

## Deployment and rollback

To roll back, restore the v1.21.0 binary. Its voice list ignores the catalog, so catalog-only voices
disappear from the picker, and saved preferences that name them fall back to the default voice.

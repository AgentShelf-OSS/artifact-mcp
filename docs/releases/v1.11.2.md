# Artifact MCP v1.11.2

## Preserve reviewed action support during collection deployment

Production already has nine revision-pinned investigation grants. v1.11.1 rejected
those action names at startup. This release includes the existing pilot support
for those exact nine actions, alongside the collection UI corrections in v1.11.1.

Each action maps to a fixed ticket route. Worker replies remain bounded and must
match the action, ticket, source, and evidence contract. Unknown action names are
rejected. Audit records use the fixed investigation operation identifier.

## Schema and configuration

Schema remains 37. Existing grants, credentials, and artifact records stay intact.
No configuration changes or schema migration are required.

## Validation and deployment

Run the action grant, route, response validation, and audit tests. Run the full
Node/Rust CI and browser suites. Verify release checksums and attestations before
installation. Run `artifact-mcp check-action-grants FILE` as the service user against the
configured grants file before replacing the live binary. This command does not
open storage or contact a worker. Retain the actual live binary and deployment record
for rollback; v1.11.1 cannot load the current investigation grants.

After installation, verify health, all collection views, folder dialog dismissal,
and the inline folder picker. Rollback preserves the database and artifact files.

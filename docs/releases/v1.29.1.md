# Artifact MCP v1.29.1

This release changes the internal structure of the server only. It continues the source split
from v1.28.1: the configuration loader and the migration ledger move into smaller modules
(PR #123). Behaviour, settings, the MCP surface and the schema do not change.

## Schema

Schema 40 before and after. No schema migration.

## Changes

| Area | Change |
| --- | --- |
| Configuration | `src/config.rs` is now the `src/config/` module, with one file per configuration section. Every `crate::config` path still resolves. |
| Migrations | `src/persistence/migrations.rs` keeps the runner and the ordered `MIGRATIONS` table. The migration bodies move to `src/persistence/migrations/`, grouped by schema range. The bodies and their order do not change. |
| Historical fixtures | The `migrationLedgerSha256` value that `cargo xtask historical-fixture` records now covers `src/persistence/migrations.rs` and every file in `src/persistence/migrations/`. The committed fixture corpus does not change. |

## Configuration and compatibility

- No new, changed or removed settings. Configuration errors and the order in which they are
  reported do not change.
- MCP surface: no change. `serverInfo.version` reports `1.29.1`.
- The two webhook URL conversion log events now have the `target`
  `artifact_mcp::persistence::migrations::webhook_urls` instead of
  `artifact_mcp::persistence::migrations`. Messages and levels do not change. Update log filters that
  match on the old module path.

## Deployment and rollback

No migration. Install the release binary as usual. The `artifact-preview` renderer has no
changes.

Rollback: the v1.29.0 binary starts on data written by this release (schema 40).

## Verification

- Item-identity scripts compared the old and new files. The differences are visibility, `use`
  lines, rustfmt line wrapping and four `include_str!` paths with one more `../`.
- `cargo fmt`, `cargo clippy -D warnings`, 1156 tests, doctests and
  `cargo xtask historical-fixture --verify-against-committed` (42/42 cases) passed. CI passed on
  the merge commit of PR #123.

## Vulnerability exceptions

None.

# Artifact MCP v1.28.1

This release changes the internal structure of the server only. It splits the largest source
files and functions into smaller modules (PR #117). Behaviour, settings, the MCP surface and the
schema do not change.

## Schema

Schema 40 before and after. No schema migration.

## Changes

| Area | Change |
| --- | --- |
| Live data | `src/data.rs` is now the `src/data/` module behind a new `DataService` port. |
| MCP tools | The tool handlers moved from `mcp/dispatch.rs` to `mcp/tools/`. |
| Startup | `src/main.rs` keeps only the composition root. Production adapters moved to `src/adapters/` and startup wiring to `src/startup/`. |
| Lifecycle | `artifacts/lifecycle.rs` is now the `artifacts/lifecycle/` module. |
| Discussion delivery | `process_discussion` is split into named stages. |
| `/mcp` route | The admission checks are named steps. Their order and the permit lifetimes do not change. |

New characterization tests cover discussion delivery (18 tests) and the `/mcp` admission order
(8 tests).

## Configuration and compatibility

- No new, changed or removed settings.
- MCP surface: no change. `serverInfo.version` reports `1.28.1`.
- Log events from moved code have a new `target` (module path). For example,
  `stale_base_detected` now comes from `artifact_mcp::mcp::tools::update` instead of
  `artifact_mcp::mcp::dispatch`. Messages and levels do not change. Update log filters that
  match on the old module paths.

## Verification

Before the merge, a differential rehearsal ran the live v1.28.0 binary and this source on
separate copies of a production backup (358 artifacts, 1,201 revisions, schema 40):

- 8,789 read requests: 0 differences after masking timestamps and nonces.
- Write phase and 33 admin steps: equal outputs and equal database fingerprints.
- Restart, `backup`, `verify-backup`, rollback to v1.28.0 and boot from the new backup: all
  passed.

The rehearsal did not cover the preview renderer, the Discord gateway or outbound network
delivery.

## Deployment and rollback

No migration. Install the release binary as usual. The `artifact-preview` renderer has no
changes.

Rollback: the v1.28.0 binary starts on data written by this release (schema 40).

## Vulnerability exceptions

None.

# Artifact MCP v1.8.0

## Release highlights

- Optional native Listen controls for authenticated HTML viewers. Listen opens a compact player;
  Expand exposes voice, speed, reading scope, preview, and sleep settings.
- CPU Pocket TTS worker with 21 preset English voices and streamed audio. An optional Pocket-only
  service profile removes other configured providers from the available voices and speech routes.
- Click a paragraph or heading to highlight it and start reading through an inline play action.
- Page, selection, from-here and section reading; pause/resume, paragraph navigation, 15-second
  rewind, saved reading positions, and supported ebook chapter continuation.
- Worker deployment examples and comparison implementations for Kokoro, Qwen and MOSS remain
  available. No speech worker is required for ordinary artifact publishing or viewing.
- Includes the organization-shared and per-viewer state bridge additions since v1.7.2.

## Schema and compatibility

The server uses schema 34. Upgrading from v1.7.2 applies the intervening state-storage migrations
from schema 32. Narration itself introduces no database migration. Reader preferences and saved
positions are browser-local; audio caches belong to the speech workers.

Charts and complex tables still use existing visible-text extraction. Semantic visual summaries,
block grouping and improved mixed-document region selection are follow-up work, not this release.

## Configuration and upgrade

1. Back up the database, artifact bodies and deployment configuration before upgrading. Record the
   current binary or immutable image digest for rollback.
2. Deploy the new server and confirm `/health` succeeds.
3. For narration, follow [Pocket setup](../../ops/pocket-tts/README.md) and the
   [TTS configuration guide](../../ops/tts/README.md). Configure worker authentication via a token
   file, enable narration, and restart the service. Do not expose workers directly to browsers.
4. To keep only Pocket, install the documented Pocket-only service drop-in. This is an opt-in
   deployment profile, not a change to provider availability for every installation.
5. Refresh open viewers to load the new player assets. Existing artifact HTML needs no changes.

## Rollback

Disable narration with `TTS_ENABLED=0`, clear `TTS_ARTIFACT_IDS`, and restart to retain ordinary artifact functionality.
Before reverting across schema versions, stop the server and restore the matching pre-upgrade
backup and configuration, then start the recorded prior binary or image. Do not point an older
server at a database migrated beyond its supported schema.

## Release process

Publish through the repository's attested release workflow after this versioned commit reaches
the default branch and passes CI. A source version bump alone does not publish release assets.

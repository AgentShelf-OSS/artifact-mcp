# Artifact MCP v1.12.2

## Same-origin artifact links

An artifact can link to another artifact on the same host, for example a review page whose
cards open each film artifact. Before this release, every such click showed the
"Open external link?" confirmation, because the frame bridge reports any link outside the
artifact's own files as outbound.

The viewer now opens a link whose origin matches the viewer's origin in a new tab directly and
clears the new tab's opener. Links to other origins, including the same host on another scheme
or port, still require the explicit confirmation. If the browser blocks the new tab, the viewer
shows the confirmation instead, so the click is not lost.

## Schema and configuration

The schema remains 38. There are no database migrations or new environment variables.

## Deployment and rollback

Verify the release checksums, manifest, and attestations before installation. Keep the current
v1.12.1 binary and deployment record for rollback. A rollback to v1.12.1 uses the same schema.

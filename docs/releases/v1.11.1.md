# Artifact MCP v1.11.1

## Collection UI corrections

Cancel and Close now dismiss folder dialogs without validating required fields or
sending a write. Cancelling a nested New folder dialog preserves the parent folder
picker and its pending selections. Cancelling deletion preserves the edit draft.

The artifact More popup includes an inline Folders control with checked memberships
and Create new folder. It stays within the viewport in the library, reel, and
ribbon previews. Membership changes preserve the popup and recover from failed
requests. Category and administrator organization controls remain in the same popup.

The Reel Shelf follows the approved folder layout: wide folder faces with preview
corners, organization and count on the folder, a New folder tile, and compact reel
controls. Selection checkboxes no longer overlap the HTML badge. Preview links can be dragged
onto folders without the hover reel disappearing during the gesture. Mobile shelf
arrows have 44-pixel touch targets.

## Schema and configuration

Schema remains 37 before and after this release. No schema migration.
No configuration changes. Both Node and Rust use the same updated browser assets.

## Deployment and rollback

Verify release checksums and attestations. Back up application data and retain the
current binary before replacement. After deployment, check health, folder dialog
dismissal, the inline folder picker, and each collection view.

For rollback, replace the binary with v1.11.0 and keep the current database and
artifact files. This patch does not change the data format.

## Validation

Regression coverage exercises real browser clicks, keyboard dismissal, form
validation, nested dialogs, menu positioning, membership writes, and failed-request
recovery. The release workflow validates both runtimes and historical fixtures.

## Vulnerability exceptions

None declared.

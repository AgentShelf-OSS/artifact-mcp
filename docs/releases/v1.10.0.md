# Artifact MCP v1.10.0

## Release highlights

Listen reads mixed-content artifacts as meaningful blocks. Reports retain surrounding text around embedded apps; figures use authored summaries, tables associate simple headers with values, and controls and timers remain silent.

The expanded player adds Current view and contextual Read details for tables, rows, code, and authored visual descriptions. Reading scopes have validated saved positions and ignore unrelated content changes. Version 1 saved positions retain fingerprint-based compatibility; invalid positions require a fresh start.

The player redesign groups playback, reading position, and voice settings. Playback controls remain visible while scrolling; the mini player displays scope, voice, and speed. Keyboard detail navigation, narrow mobile layouts, dark mode, and existing ebook/word-highlighting behavior are covered by browser checks.

The isolated browser Pocket experiment is documented; it is not enabled in the native player.

## Compatibility and configuration

Schema remains 34. No database migration, new service, or worker upgrade is required. Existing artifact HTML receives best-effort reading automatically. Optional author attributes are documented in docs/readable-artifacts.md. No automatic chart interpretation or arbitrary tool actions are performed.

Speech remains optional. The worker and authorization contract are unchanged from v1.9.0. Refresh open artifact viewers after updating.

## Upgrade and rollback

Back up database, artifact bodies, and configuration; record the current binary or image digest. Deploy the verified release and check health and representative reading flows. Rollback to v1.9.0 uses the previous binary/image on the same schema. The older player does not read new version 2 browser checkpoints; a fresh reading start may be needed.

## Validation

Focused Node and Rust response/injection tests, synthetic mixed-content and scoped-reading browser fixtures, Node/native full-player tests with simulated audio, existing ebook/selection/word-highlighting checks, and desktop/mobile/light/dark visual checks passed during development. Release CI and the provenance workflow remain publication gates.

## Vulnerability exceptions

None declared.

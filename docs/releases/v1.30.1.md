# Artifact MCP v1.30.1

This is a patch release for the v1.30.0 UI refresh. The folder dialogs now show the folder name in
the title face (PR #154). Behaviour, settings, the MCP surface and the schema do not change.

## Schema

Schema 40 before and after. No schema migration.

## Changes

| Area | Change |
| --- | --- |
| Folder dialogs | The folder name in the create dialog's live preview and in the delete confirmation uses Fraunces (`--font-title`), like every other folder title. In v1.30.0 both still used the older sans display token. |
| Documentation | Screenshots 12–14 in `docs/screenshots/` show the fixed dialogs. |

## Configuration and compatibility

- No new, changed or removed settings.
- MCP surface: no change. `serverInfo.version` reports `1.30.1`.
- No dependency changes.

## Deployment and rollback

No migration. Install the release binary as usual. No CT222 change: the preview renderer is
unchanged.

Rollback: the v1.30.0 binary starts on data written by this release (schema 40).

## Verification

- CI passed on the merge: `cargo fmt`, `cargo clippy -D warnings`, all three workspaces' tests,
  doctests, strict `cargo doc`, `cargo deny check` and the browser suites.
- Locally through `cargo-sandboxed`: 1,186 root tests and 327 browser tests passed, including the
  folder dialog journeys (`s10_collections`, `s11_collection_dialogs`). The two gallery byte
  digests changed with the inline CSS and were updated.

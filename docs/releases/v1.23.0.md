# Artifact MCP v1.23.0

## Car controls and library colors (ADR-0021)

- **Back 15 s and Speed from the car.** `media.command` accepts `rewind` and `speed` (cycles 1×,
  1.25×, 1.5×), which press Listen's own controls.
- **Current speed for new apps.** `media.session` includes `rate` only for apps advertising
  `media.rate`; v0.2 apps are unaffected.
- **Organization colors in the library.** `GET /api/library` returns `orgs[].color` (`#rrggbb` or
  `null`) so the Android app can color its car covers like the gallery. Implemented in both
  runtimes.

## Schema and configuration

No schema change (40). No new configuration.

## Deployment and rollback

To roll back, restore the v1.22.0 binary. New app versions then fall back to their built-in cover
colors and simply see no `rate`.

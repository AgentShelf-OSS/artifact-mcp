# Artifact MCP v1.24.0

## One voice list for Listen and character voices

- The main Listen voice menu and every character-role menu (ADR-0014 casts, used by ebooks) are
  now built by the same function. They offer the same voices, labelled the same way (name plus
  accent and style), with **Saved voices** first, then each engine; the Pocket list is
  alphabetical.
- Character menus update when you save or unsave a voice. The main menu keeps its search,
  Female, Male, Saved and accent filters; the current choice always stays in every menu.

## Schema and configuration

No schema change (40). No new configuration.

## Deployment and rollback

Viewer script change only. To roll back, restore the v1.23.0 binary.

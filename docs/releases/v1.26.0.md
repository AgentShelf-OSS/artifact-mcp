# Artifact MCP v1.26.0

## Stale-base guard for full-content updates

- Full-content updates now detect a body that was built from an older revision and would discard
  newer work (ADR-0023). This covers `update_artifact` with `html` or `files`, and keyed
  `publish_artifact` and `publish_bundle` that update an existing artifact.
- **Default `STALE_GUARD=warn`.** The update is written as before, and the result gains
  `warnings: [<fixed message>]`. The message points to `restore_artifact` and `discard_newer`.
- `STALE_GUARD=enforce` refuses the update with the same text. `STALE_GUARD=off` skips the guard.
- Pass `discard_newer: true` to suppress the warning or refusal for one call.
- Each detection logs `stale_base_detected id=… base=… current=… newer=… lost=… mode=…
  discard_newer=…`. The log line contains no artifact content. Use these lines to measure false
  positives before a later release makes `enforce` the default.
- `patch_artifact`, `restore_artifact`, metadata-only updates and keyed creates are not changed.
  Results without a stale detection are byte-identical to v1.25.0.

## MCP surface

Additive change. `discard_newer` (boolean) is added to the input schemas of `update_artifact`,
`publish_artifact` and `publish_bundle`. An optional `warnings` array is added to their output
schemas. A non-boolean `discard_newer` is rejected as invalid params.

## Schema and configuration

No schema change (40). New optional environment variables:

| Variable | Default | Meaning |
| --- | --- | --- |
| `STALE_GUARD` | `warn` | `warn`, `enforce`, or `off`. |
| `STALE_GUARD_MIN_SEGMENTS` | 20 | Minimum discarded segments before an update counts as stale. |
| `STALE_GUARD_MIN_SHARE` | 0.10 | Minimum share of the newer work that must be discarded, in (0, 1]. |

Invalid values fall back to the defaults.

## Deployment and rollback

No migration. The guard reads retained revisions that the server already stores. To roll back,
restore the v1.25.0 binary. The v1.25.0 input schemas do not list `discard_newer`, so clients
should stop sending it after a rollback.

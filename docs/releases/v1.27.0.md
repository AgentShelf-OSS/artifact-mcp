# Artifact MCP v1.27.0

v1.26.0 was never released. This release contains everything in
[v1.26.0](v1.26.0.md) (the stale-base guard and the float round-trip fix) plus the changes below.

## Schema

Schema 40 before and after. No schema migration.

## Rust only (ADR-0024)

The repository no longer contains or needs Node. The server was already Rust; this release removes
the Node compatibility twin and moves every tool, test runner, and service that used Node to Rust.
See [ADR-0024](../adr/0024-retire-the-node-compatibility-twin.md).

New server subcommands, so operators need only the `artifact-mcp` binary on the data host:

| Command | Replaces |
| --- | --- |
| `artifact-mcp backup [DATA_DIR] [DEST_ROOT] [KEEP]` | `scripts/backup.sh` |
| `artifact-mcp verify-backup [--database-required] [--preview-manifest-required] DIR` | `scripts/backup-coherence.py` |
| `artifact-mcp web-push-keys` | `node scripts/web-push-keys.mjs` |

Repository tooling is `cargo xtask` (run `cargo xtask --help`): `historical-fixture`, `release`
(`source-sbom`, `manifest`, `verify-manifest`, `verify-fixtures-in-image`), `cf-access-setup`,
`tunnel`, `publish-data-artifact`, and `benchmark-durability`. Flags, environment variables,
output, and exit codes match the former scripts. Backup names now use a UTC timestamp.

## Fix: anchor-bridge page paths

A bundle page path containing `$&`, `$$`, `` $` ``, or `$'` was expanded as a JavaScript
replacement pattern when the anchor bridge was injected. `` $` `` and `$'` produced a script that
did not parse, so anchoring did not work on that page. The path is now inserted literally.

## Preview renderer

`preview-renderer/` is now the Rust `artifact-preview` binary. It drives a pinned Chrome for Testing
`chrome-headless-shell` (156.0.8078.47, sha256-verified) over a DevTools pipe, with the same HTTP
contract and limits as before. Each render runs in a fresh browser process group that is killed at
the deadline. It adds network defences (a dead proxy, a blanket `NOTFOUND` resolver rule, and a
WebRTC UDP policy) that close a speculation-rules prefetch path the Node renderer let through.

- New settings: `CHROME_HEADLESS_SHELL` (the image sets it) and `RENDER_TIMEOUT_MS` (default 7000).
- The container healthcheck and smoke test are `artifact-preview healthcheck` and `smoke`.
- The renderer is a separate service; the server needs no change to use it. Native hosts follow
  `preview-renderer/DEPLOY-CT222.md` for the cutover and rollback.
- A very heavy page (about 2 MB of HTML) needs 6–7 s at a 1-CPU limit and can miss the 7 s
  deadline; give the renderer 2 CPUs or raise `RENDER_TIMEOUT_MS`.

## Configuration and compatibility

- `Dockerfile.rust` is now `Dockerfile`. Compose tags a local build `artifact-mcp:local`.
- The root `package.json` and its npm scripts are gone. Use the `cargo xtask` commands above.
- Deployment scripts that ran `node scripts/release/verify-manifest.mjs <manifest>` must run
  `cargo xtask release verify-manifest <manifest>` (or a built `xtask` binary).
- MCP surface: no change beyond v1.26.0's additive `discard_newer` and `warnings`.

## Deployment and rollback

No migration. Install the release binary as usual. To roll back, restore the v1.25.0 binary: it
starts on data written by this release (verified on a copy of production data). After a rollback,
clients should stop sending `discard_newer`.

## Vulnerability exceptions

None.

The design, nearby ideas, and how this could work

The study keeps the current gallery's preview cards, search, favorites, and restrained visual style. Reel shelf returns to the earlier folder faces with a separate hover or pinned photo reel. The compact ribbons remain another view: collection labels sit beside previews, and rows can collapse or change order. A folder is a collection of references, so the same artifact can belong to several folders. Arty's desk stays its own workspace; an inbox can come later.

01 / Familiar folders

Reel shelf

Folder faces show the artifact count and organization directly on the folder, with no caption or arrow underneath. One preview corner peeks above a closed folder, or up to three distinct corners fan out when it holds several artifacts. A brief mouse hover or immediate keyboard focus opens a temporary photo reel above the folders. Each reel card offers the existing Open, Favorite, Share, Download, admin visibility, and three-dot controls. The three-dot popup groups Category, admin Organization, and Folders, with Delete artifact separated below. Category and Folders include creation options. The popup is anchored to its trigger and stays inside the visible viewport. On phones, the reel shows one artifact at a time with touch-sized actions; paging browses the rest. When scrolling leaves too little space above, the reel opens below the folders. Placement follows the visible viewport; a small viewport lets the reel scroll within its available space. Click or tap pins the reel above the row; click again, Close, or Escape dismisses it. Open folder is a separate action. Drag onto a folder to collect.

A compact option for familiar navigation with a full gallery underneath.

02 / More visual grouping

Living contact sheets

Each folder is a large arrangement of artifact previews. One artifact fills the cover, two form a pair, and three or more form a collage. The cover adapts to the matching artifacts, including when filters are active. Drop directly onto a sheet.

Best for remembering what a collection looks like. Folder covers need more room.

03 / Compact galleries

Gallery ribbons

Every folder is a named horizontal gallery. Collapse a row to a title and a few cover glimpses. Drag its grip above or below another row, or use the move buttons. Browse the pictures without closing another folder. A shared artifact appears on each relevant ribbon with the same identity.

Reorder topics to put today’s work first, and collapse quieter collections without losing their pictures. Long collections have scrolling and arrow controls.

Folder creation and collecting

The three-dot popup keeps the existing Category and Organization selectors and adds Folders. Category offers Create new category. Organization is admin-only; a confirmed move clears links to folders in the previous organization. Delete artifact remains separated at the bottom, followed by its confirmation. Deletion and Undo are local demonstrations; production deletion retains its existing permanent-delete behavior and permissions. The Folders dropdown shows checked memberships and Create new folder. Folder checkboxes update references immediately; new categories are assigned to the artifact, and new folders can include it before returning to the same actions. Both creation forms return here when canceled.

Create a folder from the top button or the empty tile. Name it, choose a color, and see its cover before saving. With artifacts selected, the form can include them immediately. After creation, the first collected artifact becomes the automatic cover. An existing folder can use any of its own artifacts as a chosen cover.

Drag one artifact or a selected group to a folder. This adds references. It does not move the artifact out of another folder or the library. Duplicate drops do not create duplicate references. Undo restores the previous memberships or removes a newly created folder.

Ribbon collapse and order stay as you switch views, search, collect, and edit in this demo. Reordering affects the ribbons only. Undo restores the previous order. Collapsed folder headers still accept artifact drops; collapsed rows show collection cover glimpses and counts. Drag a grip near the screen edge to scroll during reordering. The ↑ and ↓ buttons offer the same ordering on touch and keyboard. Reload or Reset prototype restores the starting view.

On touch and with a keyboard, use the visible selection checkboxes and Collect buttons. The same picker adds references without dragging. Escape closes dialogs. Reduced motion keeps the final preview states.

What the prototype changes

Only this page's in-memory demonstration. No live folders, categories, titles, or artifact bodies change. Previews are captured from twelve existing artifacts in Homelab and AgentShelf and embedded in the HTML. Open original links go to those real artifacts. Image captures used a restricted local renderer; they may differ from live data or hosted font rendering.

Integration with the current gallery

The header, hero, four library totals, filter toolbar, result summary and artifact cards follow the current Artifact Index layout. A shared two-row toolbar keeps search and filters above the library views and display controls. All, Favorites, Needs review, Hidden and Uncollected share one Show dropdown. Inline totals replace the boxed statistics, and the result count appears when a filter or folder is active. The default summary row is omitted; active filters remain visible as removable chips. On phones, Display groups sorting, preview size and Grid/List while Filters groups status, organization and category. All artifacts shows the existing grid or list; the other choices display the same collection memberships as folders, contact sheets or ribbons. Grid/List appears for All artifacts, the gallery beneath a shelf, and opened folders. Collection overviews retain their own presentation; Larger previews appears only when it changes the current view.

Category remains a single metadata label. Collections are multiple references and do not replace categories. Search, quick filters, organization, category and sort apply to all three views. Collections with no matches are omitted during filtering; empty collections remain available in an unfiltered library. The sample totals describe the selected account, and Showing counts describe the active filters.

Admin preview has Administration, organization selection, Hidden, Needs review and + Category. Member preview is scoped to Homelab and uses My needs-work votes. This is a layout demonstration, not a permission implementation. Each collection belongs to one organization; collection creation asks the admin to choose one, and collecting cannot cross organizations. Share, download, visibility and category actions are demonstrated locally. Open original is the only action that leaves this preview.

Polish pass

The introduction and statistics are compact. Mobile keeps search and a Filters button visible; expanding Filters reveals the existing controls, and removable chips keep active choices visible. Collection color markers carry through contact sheets, ribbons and opened folders. Mouse hover has a 150 ms intent delay; click, touch and keyboard remain immediate. A collected folder briefly highlights and the feedback with Undo sits beside the collection controls. Reduced motion removes the entrance and confirmation animations.

Earlier studies

Topic drawers and the idea trail remain earlier alternatives. The direction here follows your preference for a visible library. Arty's inbox is deferred. The existing Arty desk concept covers advisory review.

References that informed the study

These are borrowed interaction ideas, not claims that those products organize artifacts exactly this way.

  • Are.na blocks can connect to several channels. This informs reference-based membership.
  • Cosmos collections have visual covers. This informs the preview-first folder cover.
  • Eagle's organization tools include smart folders. A later smart reel could collect matching artifacts from a saved filter.

Proposed structure

Organization → Artifacts with stable IDsOrganization → Folders with titles and coversMembership → Artifact ID + Folder IDCover → Optional artifact ID from that folderRibbon preference → Folder ID + order + collapsed state

Existing categories are single labels. Multiple folder memberships and cover choices need new product storage and controls. Keep organization access rules separate from collection membership.

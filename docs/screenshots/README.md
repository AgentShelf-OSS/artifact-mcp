# Screenshot gallery

These screenshots come from an isolated Rust v1.7.2 release-candidate server at schema 32. The
server contains twelve fictional artifacts across several test organizations and has the optional
preview renderer enabled. Artifact MCP ships light and dark themes; these examples use light mode.

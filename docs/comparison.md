# Choosing Artifact MCP

Artifact MCP is the team system around agent-made HTML. It stores pages on your infrastructure and
adds organization boundaries, a searchable gallery, revision history, review, analytics, and
notifications.

A hosted page publisher is usually the better choice when you only need one temporary or
unguessable URL. A self-hosted chat interface is a better choice when the HTML only needs to live
inside the conversation that created it.

| Capability | Artifact MCP | Hosted publish MCP | Deploy-a-page MCP | Self-hosted chat UI |
|---|:---:|:---:|:---:|:---:|
| Publish HTML through MCP | Yes | Yes | Yes | Inline only |
| Run on your infrastructure and domain | Yes | Usually no | Yes | Yes |
| Separate organizations | Yes | No | No | No |
| Organization-scoped gallery and categories | Yes | No | No | Partial |
| Revision history and restore | Yes | Partial | No | No |
| Anchored viewer feedback | Yes | Varies | No | No |
| Named view analytics | Yes | No | No | No |
| Expiring and revocable public shares | Yes | Varies | No | No |
| Per-organization notifications | Yes | No | No | No |
| Open source | Yes | Varies | Varies | Usually |

The hosted categories include products with different scopes, so check each product's current
documentation before choosing one. This comparison describes the product categories rather than
promising that every member has identical behavior.
